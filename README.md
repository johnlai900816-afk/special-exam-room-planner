# 特殊試場排列機

國中段考「考評服務」特殊試場的排列工具，照五個步驟走完就能排好考場、印出服務表與每位學生的通知單。

- 線上使用：https://johnlai900816-afk.github.io/special-exam-room-planner/
- 純前端（`index.html` 排列機＋`notice.html` 通知單），沒有後端。
- 內建的是**虛構範例資料**。

## 五個步驟
1. **學生名單**：直接匯入「考評服務名單」的 PDF 或 Word（.docx）檔，系統會讀出每位學生的服務與科目，匯入前先給你核對，讀不準的會標出來；也可以貼上名單或手動新增。檔案只在瀏覽器裡讀取，不會上傳。
2. **考程與教室**：改「考試日期」（星期、每一節、不排監考的時段、服務表、通知單都會跟著換）；填監考老師表（應授課節數、不排監考的時段、個別需求），可以把整張表直接貼上。
3. **排考場**：按「自動排列」，學生和監考老師一起排好，再拖曳微調。監考按應授課節數比例分配，延長的場次算 1.5 節，並避開不排的時段、同一時間不排兩間；下方有每位老師的監考統計與分配表。
4. **服務表**：列印或複製給監考老師與行政。
5. **學生通知單**：每位學生一張，依排法自動填好日期、考科、時間、試場與延長時間；只需補全名與個別注意事項。版面與原 Word 通知單相同。

另外有「🔍 查考場」：給導師、任課老師查學生在哪裡考，可以選年級、班級、科目、日期或直接打姓名。搭配免登入的檢視連結使用，打開連結就是這一頁；連結後面加 `&c=801` 可以直接只看某一班。

臨時支援的老師：在監考老師表按「＋ 臨時支援」，可以設定只支援某幾節、或只支援口頭作答。自動分配時先排臨時支援，其餘場次再按授課比例分給正式老師；臨時支援監考口頭作答的場次算 0.5 節。

## 排列規則
- 每間教室人數上限；延長學生同一間；指定科目（如英文）同間只放同年級。
- 電腦作答只排電腦教室；口頭回答可設每間上限、可設不與其他學生同間，排不下自動排到補考節。
- 延長時段仍在使用的教室不會被排給下一場。
- 目標：試場用得少、學生少換教室（可用滑桿調整偏好）。

## 共用與協作
右上角「與其他老師共用」：
1. 用 Google 帳號登入（第一位登入的人是主持人）。
2. 主持人輸入其他老師的 Gmail，選「可以編輯」或「只能檢視」；權限之後隨時可以改。
3. 把網址傳給對方，對方登入後就會看到同一份。

之後任何人修改名單、排法或通知單，其他人的畫面都會即時更新；右上角會顯示現在在線上的老師，以及最後是誰更新的。兩人同時改同一處時，以最後存檔的人為準。

- 組內老師用 Google 登入（編輯，或檢視＝每一頁都看得到但不能改）；組外老師用免登入連結，只能查考場。連結可以產生「某班專用」版本與 QR Code。
- 查考場可以切換「依學生／依試場」、依監考老師篩選、複製成文字貼到 LINE；組內老師另外看得到服務內容。
- 三種身分：主持人（管理名單與權限）、編輯（可以改）、檢視（只能看和列印）。
- 免登入的檢視連結：主持人可在「共用」面板開啟，拿到連結的人不用登入就能用「查考場」（只有這一頁，且連結只拿得到考場清單：班級座號、姓名、科目、時間、試場、監考，不含服務內容與通知單）、即時更新；連結可隨時關閉或換新，預設關閉。
- 資料存在 Firebase Firestore，只有共用名單內的帳號能讀，只有主持人與編輯能寫（見 `firestore.rules`，由資料庫端把關）。
- 沒登入時，資料只存在該瀏覽器（localStorage）。
- 「共用」面板最下方的「備份與還原」可下載／還原單一備份檔（含通知單補的資料）。
- 刪除或清空 `firebase-config.js` 即回到純本機模式。
