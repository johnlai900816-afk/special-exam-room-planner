# 特殊試場排列機

國中段考「考評服務」特殊試場的排列工具：依學生的服務（延長、誦讀、口頭、電腦作答、人數調整）自動排出試場，可拖曳微調，並輸出段考服務表與學生動線表。

- 線上使用：https://johnlai900816-afk.github.io/special-exam-room-planner/
- 排好後切到「⑤ 學生通知單」，每位學生一張的特殊考場通知單已經依排法填好（日期、考科、時間、試場、延長時間），之後每次調整都會即時更新；只需補上全名與個別注意事項，按列印即可。（`notice.html`，版面與原 Word 通知單相同）
- 純前端（`index.html` 排列機＋`notice.html` 通知單），沒有後端。
- 內建的是**虛構範例資料**；真實名單請用右上角「匯入設定檔」載入，或登入後由雲端同步。

## 規則
- 每間教室人數上限；延長學生同一間；指定科目（如英文）同間只放同年級。
- 電腦作答只排電腦教室；口頭回答可設每間上限、可設不與其他學生同間，排不下自動排到補考節。
- 延長時段仍在使用的教室不會被排給下一場。
- 目標：試場用得少、學生少換教室（可用滑桿調整偏好）。

## 資料儲存
- 未登入：資料只存在該瀏覽器（localStorage），可匯出／匯入設定檔。
- Google 登入：資料存在 Firebase Firestore，只有「共用名單」內的帳號能讀寫（見 `firestore.rules`）。第一位登入者成為管理者，可在右上角「共用名單」加入其他老師。
- 刪除或清空 `firebase-config.js` 即回到純本機模式。

## 隱私
含學生資料的設定檔已列入 `.gitignore`，請勿上傳到公開 repo。
