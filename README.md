# 資源班管理系統

國中資源班共用的一套系統：一份名冊，排課、簽到退、段考考場、通知單都讀它。

純前端，沒有後端。內建的是**虛構範例資料**。

## 畫面

左邊是選單，右邊是內容。

| 選單 | 內容 |
|---|---|
| 總覽 | 儀表板：學生數、組別、排課進度、段考狀態、今天的課、待處理事項、每位資源班老師的節數與個案數 |
| 名冊 | 學生、老師、教室與作息。學生可以從 Excel 貼上；考評服務會從段考考場同步顯示 |
| 排課 | 分組（可貼上整張分組表）、任課老師、不排課時段、一鍵排課（可只排某個年級）、課表輸出 |
| 段考考場 | 原本的特殊試場排列機：學生名單、考程與教室、排考場、服務表、學生通知單、查考場 |
| 簽到退 | 點名（照課表自動帶出這一節的學生）、出缺席紀錄、學生 QR 卡 |

## 各部分怎麼連在一起

1. **學生只有一份**。在名冊新增、改名、刪除，段考考場會跟著變；在段考考場匯入考評服務名單（PDF 或 Word）新增的學生，也會回到名冊。
2. **監考老師自動帶入**。名冊裡身分是「資源班」的老師會成為段考的監考老師；「應授課節數」沒有自己填的，會帶入排課結果的每週節數，監考就照這個比例分配。自己改過的數字不會被蓋掉。
3. **一份共用名單**。登入共用之後，可以使用的老師名單同時管名冊、排課與段考考場。
4. **備份是一個檔**。「備份與還原」下載的檔案含名冊、排課、段考考場與通知單。

從名冊刪除學生，段考考場裡他的考評服務會一起清掉。只在段考考場刪除的話，他還在名冊裡，所以會以沒有考評服務的狀態再出現；這次不排的學生請用段考考場的「排入」勾選。

## 排課的順序：老師優先

排課的子頁照做的順序編號：① 老師開課 › ② 任課老師 › ③ 不排課時段 › ④ 學生編組 › ⑤ 排課表 › ⑥ 課表輸出。排課表上方有「排課前先確認」：任課老師填了幾格、不排課時段匯入了沒、還有多少待安排，點一下就過去。任課老師只需要填「抽離」課的班級與科目；不鎖課的課不用原班配合。

1. **老師開課**：填每位資源班老師的基本鐘點，替他開課（科目、年級、每週節數），畫面會顯示還差幾節或超出幾節。這時候課裡可以還沒有學生。
2. **學生編組**：一張「學生 × 科目」的表，每格選「不上」、「待安排」或直接指定某一門課。
3. **一鍵排課**：先排出每位老師的課，再把待安排的學生放進同科目、同年級、不會衝堂而且人數最平均的課，最後有衝突再修正一次。

有「課程領域分組及節數一覽表」的學校，可以在老師開課頁按「貼上課程一覽表」，從 Excel 整張貼上：每一組各自的節數、型態、老師、學生一次帶入，同科目不同組的節數可以不一樣。遮名的學生名單（704林○哲）會對回名冊，對不到的會列出來；右邊的教師鐘點表一起貼會帶入基本鐘點；組名相同的課是更新不是新增，所以下學期可以直接貼新的表。

已經有現成分組表的學校，仍然可以用「貼上現成的分組表」一次建立，再到老師開課替每門課選老師。

排課頁另有「用 AI 排」：系統把題目整理成一段文字（人名全部換成 S1、T1 這類代號），貼給 AI，再把它回覆的 JSON 貼回來。套用後一樣經過衝堂檢查。程式裡 `aiPrompt`（出題）和 `aiApply`（套用）是分開的，之後要接 API 只需要在中間加一段呼叫。

## 不排課時段分幾層

排課時會把下面每一層疊在一起避開，所以不用自己記誰限制多、誰要先排。

| 層 | 用在哪裡 |
|---|---|
| 全校 | 所有組別都不排，例如全校週會 |
| 年級 | 各年級社團、班會時間不同時，分開點 |
| 學生群組 | 自己命名的一群學生，例如技藝班；有他們在的組別都會避開 |
| 班級、學生個人 | 只有某一班或某一位學生不能被抽離，例如巡迴輔導、治療 |
| 老師 | 資源班老師，以及學生原班的任課老師 |

每一層都可以「複製另一個的時段過來」。排課頁可以切換成只看、只排某個年級，其他年級排好的不會被動到。

## 排課的資料怎麼快速建立

1. **貼上分組表**（排課 › 分組）：從試算表複製整張分組表貼上，一格「班級-座號姓名」後面接各科的組別代號，會自動建立學生與組別。
2. **任課老師**（排課 › 任課老師）：班級 × 科目的表格，直接打老師名字，名冊沒有的會自動新增。
3. **不排課時段**：依上面的層次點選。

## 課表輸出

資源班老師課表、給教務處的鎖課表、鎖課清單、給導師的班級抽離表（一班一頁）、給任課老師的抽離名單（一位老師一頁）、學生個人課表、學生抽離一覽、個管個案一覽（一位個管老師一頁）、組別總表。

1. 所有表格的表頭都在 `<thead>`，印很多頁時每頁都會重複表頭。
2. **給導師的班級抽離表**：每一節寫「原班 ○○課 → 資源班 ○○（老師・教室）」，彈性鎖課時照配鎖課的結果寫原班實際鎖的科目（可能和資源班不同科）；外加課另外標「外加」，不鎖課的課寫「原班照常上課」。表頭有導師、個管老師與實施日期，最下面有「製表、日期、導師簽收」。
3. **給任課老師的抽離名單**：照鎖課找出每位原班老師，列出哪一班、哪一節、哪些學生被抽離、去上什麼。
4. **個管個案一覽**：每位個管老師的個案、所在組別、每週節數與上課節次（不印私密欄位）。學生個人課表的表頭也會寫個管老師。
5. 鎖課表和鎖課清單的標題有列印日期，最下面有「製表、日期」簽名欄。組別總表的型態欄照課的設定寫抽離、外加或不鎖課。

另有兩種照板橋國中原本的格式做的版面：

1. **總課表**：一張橫式的表，列是節次，欄是星期再分教室，每格是「科目第一個字＋組別代號＋老師的姓」（同姓的寫名字），顏色代表老師；格子另有 `.t0`～`.t11` 的樣式（依老師在 `M.rts` 的順序），印成黑白也分得出老師。組名帶著科目的（8A國文）在表上只顯示代號（8A）。可以填實施日期。
2. **學生個人課表**：一位學生一頁，列出全部節次，有課的格子是色塊（科目、老師、教室），顏色依科目。可以改課表名稱、只印某個年級。

## 手機

版面會自動改成上方選單；不排課時段改用下拉選單選對象；排課板用「點一下組別、再點要放的格子」移動。

## 簽到退

1. **照課表點名**。打開「點名」會自動跳到現在這一節，列出該到的學生；也可以選其他日期補登。
2. **三種簽到方式**。點名字、用鏡頭掃學生卡、或在輸入框打姓名或班級座號（例 70103）。接電腦的條碼掃描器等同在輸入框打字。
3. **狀態**。點一下簽到，再點一下簽退；上課超過 5 分鐘（可調）才到算遲到；「⋯」可以改成請假、缺席或加備註。過了下課時間還沒簽到的顯示未到。
4. **出缺席紀錄**。可選今天、本週、本月或自訂期間，列出每位學生的應到、實到、遲到、請假、缺席與出席率，點學生看明細，可列印或複製。只計算有點過名的節次，所以放假不會被算成缺席。第一次點某一節時，會在紀錄裡存下當時的名單（`_roster`）和組名、節次名稱（`_info`）：學期中才加入的學生不會被算成之前每節都缺席；新學期清掉組別後，統計也還在。舊紀錄沒有名單的，只從學生在那一組第一次有紀錄的那天開始算。
5. **公開提醒與私密備註**。名冊的「公開提醒」會在簽到時顯示給學生看；「個管私密備註」、IEP 會議日期、下次檢討日、鑑定有效期限放在名冊的「私密欄位」（勾選才顯示），不會出現在簽到畫面，也不會印出來。舊資料的備註第一次開啟時會先搬到私密備註。總覽會提醒本月到期的日期。
6. **學生卡**。每人一張 QR 卡，可依班級或組別篩選後列印。
7. **多台裝置**。登入共用後，點名紀錄一天存一份，逐筆合併寫入，兩台裝置同時點名不會互相蓋掉。

## 衝堂檢查與手動調整

排課頁上方有一列「衝堂檢查」，每次調整都會重新算，分成：老師、學生、原班兩科、任課老師、教室、不排課時段、還沒排。有問題時上面會列出紅字，點一下就跳到那一節。

點一下課表上的組別，會出現編輯列：可以改這一節的教室、固定或解除固定、拿下來，或點別的格子移動（綠色是不會衝堂的位置）。放到會衝堂的位置也放得進去，只是會被標出來。

在「不排課時段」改了設定後，如果已經排好的課落在新的不排課時段，會立刻提醒。

## 排課規則

下面每一條都可以在「名冊 › 教室與作息」最下方開關或改數字。


一定要遵守的：

1. 資源班老師不排課的時段不排，同一節不會有兩組。
2. 學生同一節不會在兩組。
3. 抽離課：這一組學生原班的任課老師，只要有一位不排課，那一節就不排。
4. 抽離課：同一個班同一節不會被要求上兩科。
5. 抽離課：同一位普通班老師同一節不會被兩個班同時鎖課（可在「名冊 › 教室與作息」最下方關閉）。
6. 外加課只排在勾了「外加時段」的節次，抽離課只排在一般節次。
7. 全校共同不排的時段不排；同一節的組數不超過教室數。

盡量做到的（排不開時可以超過，畫面上寫「盡量不超過」）：同一組一天只上一節；資源班老師每天節數平均、不連上超過三節；學生一天被抽離不超過三節。

## 鎖課方式

抽離課要請教務處把原班的課「鎖」在同一節。各校做法不同，在「名冊 › 教室與作息」最下方選：

1. **原班和資源班同一節上同一科**：資源班上國文時，學生的原班也一定要排國文。任課老師不排課的時段、同一位老師教的兩個班，都會直接限制排課。
2. **彈性鎖課**：先排資源班課表，再替每個「有學生被抽離的班級 × 節次」配一科來鎖。優先鎖同一科；鎖不到（老師不排課、被別班鎖走、該科節數用完）就改鎖其他主科；都不行就列為鎖不到。同一位老師同一節只會被一個班鎖。可以設定各科每週最多鎖幾節，以及鎖到只剩 1 節時要保留連堂的科目（系統會在旁邊多鎖一節，或少鎖一節）。

彈性鎖課時，一鍵排課排完會再做一次收尾，把鎖不到的節次換到鎖得到的時段。排課頁的衝堂檢查列會顯示「鎖不到課 n／總數」；「課表輸出」有鎖課表、鎖不到的清單，以及和教務處試算表相同欄位的鎖課清單。

課的型態有三種：抽離（要鎖課）、外加（只排早自習這類時段）、不鎖課（排在一般節次，但不需要原班配合，例如社會技巧）。

班級層級的時段分兩種：「不能被抽離」和「不能鎖課」（例如導師時間、本土語、特色課程）。後者只影響鎖課，不鎖課的課仍然可以排。從 Excel 帶入班級不排課時，預設全部當成「不能被抽離」（完全鎖定，不會排課進去）；也可以改成只鎖定勾選的原因（系統會列出表裡出現過的原因）。

已經手排好的鎖課（特教鎖課需求的「資料輸入」或「資料輸出」）可以一起上傳或貼上，排課時會盡量排回這些節次，配鎖課時優先用手排的老師；不想沿用就在「學期初匯入」清除。教務處整理好的班級不排課、教師不排課，可以在「不排課時段」頁按「貼上不排課表」整張帶入。

## 每學期怎麼更新資料（學校自己來）

「名冊 › 學期初匯入」放每學期要帶進來的表；「名冊 › 資料與備份」放下載備份、從備份檔還原、自動保留的版本、開始新學期、全部清空。

1. **開始新學期**（資料與備份）：勾選要清掉的部分（排課結果、課程、任課老師、班級不排課、老師不排課）。新學年可以勾「升年級」：七年級變八年級、八年級變九年級（701→801），九年級學生畢業移出名冊；因為班級號碼會變，課程、任課老師、班級不排課、全校課表和各班導師會一起清空，之後要讀入新學年的全校課表。
2. **上傳學校的 Excel**：一次選好幾個檔案，系統自己認出學生名單、任課老師名單（教務處的教師名單）、課程一覽表、班級不排課、教師不排課，其他工作表略過。列出來之前會先試算一次，帶不出資料的工作表不會列。Google 試算表要先下載成 Excel。檔案只在瀏覽器裡讀，不會上傳。
3. **資料清單**：每一種資料目前有多少、來自學校的哪一份表，每列都有「貼上」可以單獨更新。
4. 補上資源班老師自己的不排課時段，再到排課頁按一鍵排課。

各頁也都有對應的「貼上」：學生名單（可多一欄個管老師、一欄備註）、任課老師名單（老師頁與任課老師頁）、課程一覽表、不排課表。老師頁另有「移除沒用到的任課老師」。

匯入時要注意的幾件事：

1. **學生名單**：同班同名的會更新；座號相同但姓名不同（可能是轉入或換座號）不會蓋掉原本的學生，而是另外新增，再列出來，每筆都有「刪掉舊的」按鈕。名冊裡沒有的個管老師會自動建成資源班老師，並列出來。有「導師」欄時另外存成各班導師。名單上的「備註」存成個管私密備註。
2. **老師的名字**：所有匯入（學生名單的個管老師、任課老師名單、課程一覽表、不排課表、手排鎖課）都用同一個 `normName()` 比對，去掉空白和「老師、主任、組長、導師、校長、教師」，所以「王」「王老師」「王 老師」是同一位，不會重複建立。
3. **課程一覽表重貼**：表上有名字對不到名冊時，原本在課裡的學生先留著，標「表上沒找到」列出來；全部都對得到才照表更新名單。授課教師寫兩位（「王老師、李老師」或「王/李」）時，第一位當授課老師，其他的列出來。
4. **從課裡拿掉學生**：如果他這一科已經沒有別的課，會問「是不上這科了，還是改成待安排？」，不然一鍵排課會把他放回去。
5. **刪除**學生、老師、課、教室之前會自動保留一份版本，刪完 8 秒內可以按「復原」。刪除有個管學生的老師時，會先問由誰接手。

### 改壞了怎麼辦

每天第一次修改，以及匯入、開始新學期、一鍵排課、刪除、還原之前，這台電腦都會自動留一份版本（最多 12 份），在「名冊 › 資料與備份」可以回到任何一份。這是存在瀏覽器裡的，換電腦或清除瀏覽器資料就沒了，所以仍要定期按「下載備份檔」；總覽會在超過 14 天沒下載備份時提醒。

## 學校自己的雲端

想讓幾位老師共用同一份、又不依賴別人的帳號，可以讓資料存在學校自己的 Firebase（免費方案即可，建議用學校或處室的公用 Google 帳號建立，人事異動時交接帳號就好）。不用改程式，在網站裡設定：

1. 按左下的「備份與還原」或「共用」，打開「學校自己的雲端」，照裡面的步驟做：建立 Firebase 專案、建立 Firestore（asia-east1）、貼上「複製安全規則」的內容並發布、啟用 Google 登入並把網站網域加入已授權網域、把 firebaseConfig 貼進來按「套用」。
2. 第一位登入的人是主持人，這台電腦的資料會傳上去當第一份。
3. 按「複製給同事的設定連結」傳給同事：連結裡帶著設定（`#cloud=…`），同事點開時會先問過才套用，再用自己的 Gmail 登入，主持人把他加進共用名單。

設定存在各台電腦的瀏覽器裡（`school.js` 讀），會取代網站內建的設定；也可以改成「不使用雲端（單機）」或改回內建。Firebase 的網頁設定本來就是公開的資訊，資料的安全靠登入與安全規則。

## 全校課表與段考交卷名單

「名冊 › 全校課表」可以選學期初拿到的全校課表 PDF（每班一頁、底下有「科目、老師、節數」統計的那種），七、八、九年級的檔案可以一次選。

文字 PDF 直接讀。掃描成圖片的 PDF 會在瀏覽器裡用文字辨識（Tesseract），只辨識底下的統計和左下角的編號，一頁大約一秒，第一次要下載約 20MB 的辨識資料。辨識出來的名字會對照名冊、任課老師和教師不排課裡的老師名字；整份一起讀時，也會看同一科在別班是哪位老師，來補認錯字。還是認不出來的標成橘色，點班級會看到截下來的統計圖，對照著改。

比對的規則（`ttNameFix`、`ttSubjCand`）：

1. 名字用編輯距離比：少一個字、多一個字（蔡珊→蔡依珊）或形近字（已／己、未／末、珊／姍、于／於、婷／停、髓／體、依／侑…，見 `TT_LIKE`）算小錯，而且要明顯比第二像的近，才自動改。只差一個普通的字（陳美華和陳美玲）只當「推測」，標橘色讓人確認；只對上一個字的不猜。推測的名字存成 `x[2]=2`，不會被當成確定的老師拿去用。
2. 兩個字的科目要完全相同或只差形近字才認（髓育→體育）；差一個普通的字（家長、生活、理由、體重）一律標待確認。三個字以上的科目差一個字（類語文），要老師確定教這一科才算數。
3. 節數超過 9 不截斷，標待確認。
4. 班級編號接受三碼（年級是第一碼）或四碼（10～12 年級，年級是前兩碼）。
5. 「班級」欄改成另一個已經有課表的班級時，會先問要不要蓋掉。

讀完會列出每班國英數社自的老師，並且和學生名單對照：名冊有學生但課表沒有的班級、任課老師和課表不一樣的格子，以及每位學生各科的老師。按「用課表更新任課老師」可以把國英數理的任課老師一次改成課表的。

段考頁的「服務表」多了「交卷名單」：每一科一張 A4 直式，照學校原本的紙本格式，依年級分三欄，每位學生後面有「□已交□未到」和批閱教師。批閱教師從全校課表找（作文、國文找國語文老師，社會找歷史、地理、公民老師，自然找生物、理化、地科老師），沒有課表時用各班任課老師，都沒有就留白讓學校手寫。

## 教室與備用教室

「名冊 › 教室與作息」可以改教室名稱、新增或刪除教室。勾「備用」的教室平常不排：同一節最多排「沒勾備用的教室數」組，真的排不下才會用到備用教室，總數不會超過全部教室數。分配教室時也是先用平常的，最後才用備用的。

## 怎麼開

需要用網頁伺服器開，不能直接點兩下 `index.html`（段考考場那一頁要和外殼互相讀資料，瀏覽器不允許本機檔案這樣做）。

1. 放到任何靜態網站空間（GitHub Pages、Firebase Hosting、Netlify 都可以）。
2. 或在這個資料夾執行 `python -m http.server 8765`，再開 `http://localhost:8765`。

## 登入與多人共用

預設是單機模式，資料只存在該瀏覽器。要讓幾位老師共用，每間學校做一次：

1. 到 Firebase 主控台建立專案，啟用 Authentication 的 Google 登入，建立 Firestore 資料庫。
2. 在專案設定新增網頁應用程式，把設定貼到 `firebase-config.js`，取代 `null`。
3. 部署資料庫規則：在這個資料夾執行 `firebase deploy --only firestore:rules --project 你的專案`。
4. Authentication 的「已授權網域」加入網站的網域。
5. 打開網站，第一位登入的人成為主持人，再加入其他老師的 Gmail，選「編輯」或「檢視」。

如果這間學校已經在用「段考特殊試場排列機」的 Firebase 專案，可以直接用同一個專案的設定：`firestore.rules` 已經包含排列機原本的規則，共用名單也是同一份。注意：部署規則會取代該專案現有的規則。

登入後會改用雲端的那一份；雲端還沒有資料時，會把這台電腦現在的資料傳上去當第一份。兩人同時改同一處時，以最後存檔的人為準。
